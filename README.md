# tiler

A keyboard-driven tiling window manager for Windows, inspired by [AeroSpace](https://github.com/nikitabobko/AeroSpace).

> Work in progress — not usable yet.

## Goals

- i3-like layout tree with `tiles` and `accordion` layouts
- Its own virtual workspaces, independent of Windows Virtual Desktops — switching is instant
- One command language shared by the config file and the `tiler` CLI
- Plain-text TOML configuration with hot reload
